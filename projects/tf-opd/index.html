At a glance

The paper in four results.

What if putting specialists back into one model took no training at all? When they share a base model, every layer of the merged model has an exact solution, computed from the specialists’ own answers with forward passes only.

The problem

Putting specialists back into one model has meant training again, or ignoring their own answers.

Reinforcement learning turns one base model into specialists: one far ahead in mathematics, another in code, each far behind in the other’s domain.

{% include proj/tf-opd/routes.html %}

Only TF‑OPD needs no training and still learns from the specialists’ own answers.

The idea One layer at a time

For one layer, distillation is least squares, and it has an exact solution.

Ask each layer of the fused model to reproduce every specialist on the inputs that specialist sees while reading its own answers. The solution needs only the second moments of those inputs.

{% include proj/tf-opd/idea.html %}

Task arithmetic applies every update to every input. TF‑OPD fits each specialist where its inputs are.

How it works

Four steps, and not one gradient.

Steps 1 to 3 are forward passes of each specialist on its own answers. Step 4 is linear algebra.

  • no backward pass
  • no optimizer state
  • no learning rate
  • no evaluation problems
{% include proj/tf-opd/pipeline.html %}

The statistics come from each specialist reading its own answers: the inputs a layer actually sees in use.

The evidence Finding 01

One model, ahead of both specialists on average.

A math specialist and a code specialist of Olmo 3 7B, merged with forward passes only.

Olmo 3 7B on MATH-500, OlympiadBench, AIME24, AIME25, HMMT25, HumanEval+ and MBPP+. Left: dashed lines mark what each specialist reaches on its own domain.

Built without a gradient step, it is on average better than either specialist it was built from.

The evidence Finding 02

Close to the best on every benchmark.

Each specialist is far ahead in its own domain and far behind in the other. The fused model is never far from the best score.

Accuracy (%). AIME24, AIME25 and HMMT25 average four sampled answers per problem; the others use one. Released checkpoints are scored in bfloat16, the fused model in float16.

It equals the math specialist on AIME24, edges past it on OlympiadBench, and keeps most of what reinforcement learning added everywhere else.

The evidence Finding 03

What the rollouts contain matters more than the solver.

A few of the math specialist’s answers never end: it starts repeating itself and runs to the length limit. Every token counts in the statistics, so these few answers weigh a lot.

AIME25, four sampled answers per problem. The fused models and the math specialist are scored in float16; task arithmetic is stored in bfloat16.

Why the fit per token hides it

The model built from all answers follows the specialist almost token for token, yet scores the same as task arithmetic on AIME25: a long derivation is decided at a few of its steps.

Removing the looping answers alone brings it level with the specialist, and recovers every hard problem the model built from all answers loses.

Why it matters

After reinforcement learning, putting specialists together may not need training.

Trained distillation spends forward passes at every update and adds a backward pass each time. The closed form pays for its data once.

{% include proj/tf-opd/cost.html %}

What this opens up

Add a specialist, add a term

A new specialist costs its rollouts and one more term in each layer’s sums. Nothing is retrained.

Nothing to tune

No optimizer state and no learning rate: forward passes, then one linear solve per layer.

Data you can choose

The statistics are a picture of each specialist’s own answers, and which answers enter them decides the hard problems.

What a trained student is asked to do, match each teacher on the text the models generate, has an exact layer-wise solution. For specialists that share a base model, that solution already gives one model close to each teacher and more accurate on average than either.
