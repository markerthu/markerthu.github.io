LBC: A unified framework for behavior control in deep RL — superhuman performance with a fraction of the data

TL;DR — Population-based RL methods improve exploration by running diverse policies, but are fundamentally limited by a fixed, predefined population. LBC breaks this limitation by learning a hybrid behavior mapping over all policies, enabling a dramatically enlarged behavior space — and achieves superhuman performance with 100× less data.

{% include film-card.html id="lbc" name="LBC" %}

The core idea

Population-based methods fix a set of exploratory policies and select between them. LBC instead constructs a continuous, learnable behavior mapping space that blends all policies, then uses a bandit-based meta-controller to learn which behaviors to select at each moment:

{% include anim/strip_lbc.html %}

The Blend stage is what lifts the fixed-population limit: from the same policies, LBC can select from a dramatically enlarged behavior space.

{% include anim/lbc_space.html %}

The Select stage is learned too: episode returns update the bandit, so it learns which behaviors to select.

{% include anim/lbc_bandit.html %}
