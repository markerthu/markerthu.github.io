Who stops by

Where readers of this site come from, what they read, and how they got here.

Measured with GoatCounter, an open-source analytics tool. No cookies, no tracking across sites, and no IP addresses are stored. Location is resolved to a country, and to a state or province for the few countries that report one — never to a person. Refreshed every three hours; last run covered {{ v._updated }}{% if v._timezone %} ({{ v._timezone }} time){% endif %}, so “today so far” only counts up to the last refresh.
