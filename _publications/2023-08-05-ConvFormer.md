ConvFormer revisits Transformer-style models for sequential user modeling, the recommender task of predicting the next item a user will want. An analysis of the item-to-item mechanism yields three criteria for efficient sequential user models; ConvFormer, a simple modification of the Transformer that meets them, reaches state-of-the-art results, and an acceleration technique keeps it efficient on long behavior sequences.
